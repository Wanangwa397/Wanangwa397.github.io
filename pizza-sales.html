Pizza Sales Performance Analysis

A Power BI dashboard analyzing pizza sales performance, ordering patterns, peak business periods, product preferences, and lower-performing menu items.

Power BI DAX Power Query Data Modeling Data Visualization

Project Overview

This project uses Power BI to analyze pizza sales and customer ordering behavior. The dashboard summarizes key business metrics including total sales, total orders, average daily orders, and the average number of pizzas per order.

Key Analysis Areas

The dashboard examines monthly order trends, busiest days of the week, peak ordering hours, preferred pizza categories, preferred pizza sizes, and the lowest-performing pizzas by sales. Interactive filters allow users to explore performance by pizza size and category.
