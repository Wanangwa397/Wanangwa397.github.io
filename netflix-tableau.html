About the Project

This dashboard provides an overview of Netflix's movie and TV show catalog and allows users to explore how content is distributed across countries, ratings, genres, content types, and years.

The dashboard also includes title-level filtering so users can select individual titles and view details such as type, rating, release year, duration, date added, genre, and description.
