Student Performance Analysis

A Power BI dashboard designed to explore student academic performance, grade patterns, and overall performance trends.

Power BI DAX Power Query Data Visualization Data Analysis

Project Overview

This project uses Power BI to analyze student performance data and present the results through an intuitive dashboard. The analysis focuses on identifying patterns in grades, comparing performance across different groups, and summarizing key academic indicators.

Project Objectives

The primary objective was to transform student-level data into a clear visual report that makes performance trends easier to understand. The dashboard provides a concise view of academic outcomes while allowing users to explore the underlying patterns in the data.
