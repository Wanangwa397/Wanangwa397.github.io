Social Media Performance Dashboard

A Power BI social media analytics report focused on audience growth, impressions, engagements, posting activity, top-performing content, and platform-specific performance across Facebook, Instagram, and X.

Power BI DAX Power Query Social Media Analytics Performance Tracking Data Visualization

Project Overview

This project uses Power BI to analyze social media performance across multiple platforms. The report includes an overall performance view as well as separate pages for Facebook, Instagram, and Twitter/X. Key measures include followers, impressions, engagements, posting activity, and month-over-month performance.

Key Analysis Areas

The analysis highlights audience growth, engagement patterns, impression trends, and top-performing posts. Each platform page provides additional detail, including monthly performance indicators, post or tweet volume, top posts by engagement, and impressions by day.
