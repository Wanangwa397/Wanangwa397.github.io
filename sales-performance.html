Sales Performance Analysis

A Power BI sales dashboard analyzing revenue, orders, customers, product performance, sales channels, geographic trends, courier performance, and product returns.

Power BI DAX Power Query Data Modeling Data Visualization

Project Overview

This project uses Power BI to provide a high-level overview of sales performance across products, countries, sales channels, and couriers. The dashboard summarizes key business metrics including total sales, total orders, total customers, and average order value.

Key Analysis Areas

The dashboard examines monthly sales trends, product-level performance, courier performance, geographic sales results, and product return status. A detailed transaction view is also included for deeper analysis by invoice, customer, category, country, payment method, and sales channel.
